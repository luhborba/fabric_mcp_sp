## 📋 Checklist pré-requisitos

Antes de começar, certifique-se que tem:

- ✅ Python 3.11+ (`python --version`)
- ✅ Git (`git --version`)
- ✅ ODBC Driver 18 (se vai usar Warehouse)
  - Windows: [download ODBC](https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server)
  - macOS: `brew install microsoft-odbc-driver`
  - Linux: Ver [INSTALLATION.md](INSTALLATION.md)
- ✅ Service Principal credentials (Tenant ID, Client ID, Secret)
  - Ver [README.md](README.md) § Configuração Azure AD

## 🚀 Workflow recomendado

### Dia 1: Setup

```
1. Ler QUICK_START.md (5 min)
2. Instalar dependências (10 min)
3. Registrar MCP no seu IDE (5 min)
4. São primeiro teste: "List workspaces" (3 min)
   
Total: 23 minutos
```

### Dia 2: Explorar

```
1. Ler README.md completo (15 min)
2. Explorar TOOLS_SUMMARY.md (10 min)
3. Tentar 3-4 prompts diferentes
   - "Descreva o workspace [ID]"
   - "Liste os lakehouses"
   - "Mostre a schema do modelo [ID]"
   
Total: 45 minutos
```

### Dia 3+: Automatizar

```
1. Ler exemplos em README.md § Exemplos
2. Planejar sua automação (workspace, pipeline, etc)
3. Usar Claude para gerar código
4. Iterar até funcionar
```
